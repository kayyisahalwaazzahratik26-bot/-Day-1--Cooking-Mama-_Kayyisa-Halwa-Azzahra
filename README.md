Apa itu Repository ?
Repository merupakan tempat untuk menyimpan project di GitHub yang dapat 
berupa file dan folder juga menyimpan riwayat perubahan dari file/folder yg diunggah

Apa gunanya Repository ?
Repository berguna untuk menyimpan file project dan bersifat online jadi tidak hilang 
bila file di penyimpanan komputer bermasalah, juga bisa digunakan oleh beberapa orang

Jenis AI 
Terdapat 2 jenis AI yaitu ;
1. AI untuk membuat dan mengembangkan sebuah proyek seperti Chat GPT, Claude.AI, Gemini Ai,
   Deepseek AI, dan Grok
2. AI untuk me-manage perubahan dan kolaborasi seperti Git (untuk mengontrol sistem kendali versi),
   GitHub (platform berbasis web cloud untuk meng-host proyek Git), BitBucket (Layanan manajemen
   repositori kode berbasis web), dan GitLab (platform DevOps lengkap berbasis web yang juga menyediakan
   repositori Git, manajemen proyek, dan otomatisasi CI/CD).

Prompt
Merupakan instruksi/masukan yang kita berikan kepada sistem AI untuk mendapatkan hasil tertentu. Prompt harus
memiliki context yang rinci bila ingin hasil prompt memuaskan dan minim cacat. Struktur prompt yang dapat digunakan
agar mengahasilkan sesuatu yang minim cacat yaitu ;
1. Role
   Bertugas Bagian ini memberi tahu AI harus berperan sebagai apa dan untuk siapa
2. Task
   Berisi inti permintaan user, apa yang sebenarnya mau dikerjakan dalam bentuk yang jelas, singkat, dan fokus pada
   satu tujuan utama
3. Context
   Berisi detail pendukung supaya hasilnya sesuai kebutuhan. Di gambar, bagian ini mencakup dua hal
   yaitu Requierements (Persyaratan) dan Constraints (Batasan)
4. Format
   Menentukan bentuk jawaban yang diinginkan. Jadi AI tahu harus memberi apa saja, seperti kode lengkap,
   cara menjalankan, dan cara mengujinya

Keuntungan Prompt Engineering
1. Meningkatkan performa AI model
2. Mengurangi bias dan respon yang menyinggung
3. Meningkatkan kontrol dan predictability
4. Memberikan pengalaman yang lebih baik
